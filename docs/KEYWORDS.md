# 预置检索关键词库

SOP 阶段 1 的选词表。每个领域按「主题词 + 视角词」组合，使用时至少覆盖三个视角。时间参数默认近 1 年（2025-08 至 2026-08），时效性强的议题缩至近 3–6 个月。

## 金融投资 / 个人理财

主题词：资产配置、家庭理财、指数基金、定投、储蓄、国债、存款利率、黄金、保险、退休规划、现金流、通胀

视角词组合示例：
- 资产配置 + 方法（标普家庭象限、股债比、再平衡）
- 定投 + 回测 / 亏损应对
- 存款利率 + 现状（2026 年最新利率）
- 家庭理财 + 新手 / 避坑
- 退休规划 + 养老 / 储蓄目标
- 通胀 + 购买力 / 保值

可用插件：finance-workflows、financial-statements、variance-analysis。

## 科技 / 新材料（2026-08-08 回填）

主题词：前沿材料、二维材料、量子技术、材料制备工艺、产业化

视角词组合示例（已验证有效，脱敏后通用化）：
- 主题词 + 突破 / 进展（命中官方信源与主流媒体）

已验证有效的通用组合模式（可直接复用）：
- "<机构名> <技术名> 突破"（Web，命中官方信源）
- "<材料名> <tech keyword> <institution>"（Web，命中国际报道）
- "<行业名> 企业数量 <数据来源>"（Web，命中口径出处）
- "<材料名> 概念股 炒作 历史"（Web，命中炒作史）

## 通用技巧

- 每个问题准备 6–12 组关键词；公众号检索用 3–4 组，Web 核查用 2–3 组。
- 公众号检索必须附时间参数；搜狗微信按时间过滤。
- 找不到结果时，先拆词（主题词拆成更小概念），再换视角词。
- 反方/争议议题用关键词 + 「风险 / 反驳 / 失败 / 反面」后缀。
- 高赞定位用「知乎 问题关键词 + 高赞 / 热门回答」。
- 事件型议题：先用「事件 + 关键词」锁定公告原文，再用「动机 / 成本 / 反对」拆多角度。
- 每次研究结束后，把有效关键词组合回填到此库。
