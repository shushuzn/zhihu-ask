# 知乎文风与排版指南

报告正文的写作规范。核心原则：信息密度高、结构可扫读、数字可核查、**纯事实陈述、不带立场、不下结论、不替读者做判断**。

## 文风（中性客观）

- 只陈述事实、数据、结构、口径，不做价值判断。
- 不写"我认为/我的判断/结论很硬/这不合理"等立场表述。
- 不评价主体（如"太猛了""其实很厉害"），不贴标签（如"神话""罪证"）。
- 不下建议、不站队；涉及未来判断时只给多情景与方向性/概率性陈述，不伪装成确定预测。不写"判断权留给读者/留给你"等元话语提示词（成品正文零提示性套话，quality_check 拦截；结论用事实映射句式表达多口径并存）。
- 承认不确定：无法核实的标"未见公开数据/推算"，不伪装成事实。
- 可用"据 XX 数据""Wind 数据显示""媒体报道"引出事实。

## 结构

- **概念主体**：正文叙述主体是**概念/事件/对象本身**，来源材料（用户发的链接、博客、论文）只用于提炼概念与提供素材，来源交代一律放文末「参考文献」区。**禁止转述体/汇报腔**：正文不得出现"以下解读 XX 的博客/文章""XX 文章的价值在于""这篇论文讲了"等把来源材料当叙述主语的句子；判断标准：删掉"这篇文章/博客/论文/解读"字样后正文是否依然成立，成立即合规。**句首禁止裸"这篇/该篇/本篇/此篇"指代**（必须接"论文/文章/报告/研究/笔记"等实体名词构成主语）。来源材料中的方法、定理、结论直接以概念本体陈述。
- **可读性**：目标读者为对主题感兴趣的专业/准专业读者。**深度与严谨优先**——技术结论、数据、论证链完整保留；术语首次出现给简洁准确的定义（不做生活化类比稀释），公式符号首次出现说明含义，长句可拆但不牺牲精度；自检：每个小节能否让读者清楚"它在解决什么问题、结论从哪来"。
- **标题即质量（反空洞标题）**：大标题直给核心判断（例：`傅里叶级数到变换的严格化不在极限本身`），小标题落到函数空间/技术机制（例：`启发式推导为何只能作动机` / `Schwartz 空间上的严格定义与同构` / `三类延拓的分层规律` / `如何区分动机与定义：按函数类选择判据`）；禁止空洞标签（`因果/结构/规律/策略` 为模板占位，不是成品小节标题）。**优秀文章锚点（3 秒钩子 / 金字塔证据链 / 可视化收尾）**：开头 300 字用反常观点/故事悬念/权威承诺三选一钩子（如“严格化不在极限本身”），让读者 3 秒抓住冲突；正文按 WWHE（What/Why/How/Example）或痛点→剖析→方法→判据的金字塔递进组织，每个观点配数据/案例/个人经历之一；结尾复述价值 + 互动提问 + 延伸资源，排版每段 ≤5 行、空行分隔、关键词加粗、每 300–500 字 1 图。
- **机检边界**：可读性本质靠人工复核，机器仅能查客观指标（标题/结论长度等），不据此加硬性机检。
- **开头结论段前置（首行不写"结论"字样）**：标题行后即给事实性结论（≤300 字符），直接回答原问题；用**反常识事实或关键数字反差**开篇抓人（如"1 万小时仅为最优秀组在单一时间点的平均值"），让读者 3 秒内抓住增量信息，再进入分节事实。
- **报告形态（单章节平铺，参考 centuries-obvious-skills）**：H1 标题 → 结论段 → 多个 `###` 无编号小节（按主题切分，数量由内容自然决定，不设上限）→ `## 参考文献`。无顶层内容章节；研究问题/多维分析全部融入小节，不单列章节。
- **小节内结构**：小节 = 引入句（事实+关键数字加粗）→ 内容按型组织——**并列多条同类信息用 `1. 2. 3.` 有序列表**（点数由内容自然决定、不强行凑数/对称；单句信息并入叙述段不单独成点）、**多实体对比用 Markdown 表格**、**因果/演化逻辑链用连贯叙述段** → 算式叙述融入（算式写在句中，如"时滞为 1948 − 1648 = 300 年"）→ 分析表格（按需：对标/解释链/风险）。**禁止无序 bullet**（`- ` 会被"小点未叙述化"拦截），**禁止"第一……第二……"式长段落**（同义于列表的内容必须列表化）。
- **逻辑严密（因果链串联）**：小点间用"但/因此/由此/同期/然而"等因果连接词衔接，先因后果、层层递进；禁用无逻辑的平铺罗列。一个段落只讲一个点，段间用事实衔接。
- 每段不超过 4–5 行。
- 拆解类内容（如归因、贡献拆分）注明推算/推断口径与假设。
- **算式融入叙述（按需但必写）**：有计算价值的内容（证明机制/技术参数推导）算式必须写、按主题融入对应小节；算式与数字保留在句中、结果数字加粗；口径/边界/局限也写进叙述（防单向推断）。禁止为凑数硬造算式，也禁止该写不写（数学/证明类内容的机制算式是正文的一部分）。
- **论证完整（数学/证明/机制类内容）**：必须给出完整论证链（定理-引理-证明结构或步骤归约），禁止只给结论或方法名概述、禁止省略证明步骤；来源论文的论证结构以论文全文为准（抓取 arXiv HTML 版），不凭摘要臆测。
- **成品零过程字样**：正文不得出现"第 N 轮/迭代/R\d/本轮/更新/第一版/**通道 X**（检索通道标记）"等研究过程标记（多轮迭代与检索通道过程只记录于 process_notes/round_notes/素材库）；quality_check 自动拦截，交付前自查一遍。
- **禁 A 股行情信息**：正文禁止提及股票代号（如 603986）、股价（现价/收盘价）、涨跌幅、总市值/流通市值、PE(TTM)/市盈率、换手率等 A 股行情信息；如需产业格局背景，用公司名+产业事实表述（如"长鑫存储拒绝苹果压价"），不用行情数字；quality_check `check_stock_info` 自动拦截。
- **多方主体刻画（避免同质罗列）**：涉多方主体（机构/人物/阵营）时，每个主体用"关键事件+关键数字"刻画差异（如"红杉 2019 年当场过会领投；美团 2023 年估值 10 亿时投入约 4 亿、浮盈超 49 亿"），不写"X 持股 N%、Y 持股 N%"式纯罗列；不贴评价性标签（"最 XX 的 XX"属媒体定性，须转述归因而非自行断言）。
- **分析层层递进（由表及里）**：多维分析可按"表层事实 → 深层逻辑 → 系统层面"组织（如"表面是投一家公司，深层是投赛道，系统层面是产业链闭环"），先给读者看得见的数据，再给背后的结构，增加分析纵深；每层仍只陈述事实，以表格形式融入小节末尾。

## 数据呈现

- **正文引注**：正文按 GB/T 7714-2015 顺序编码制在引用处标注 [n]（置于所注内容之后、标点之前，如"……52 行 JavaScript[1]"）；文末「参考文献」按正文首次引用顺序编号著录，编号从 1 连续。数据可溯源交给文末「参考文献」区；check_gbt_refs 校验引注与文献列表一一对应（无悬空引注、无未引用条目、编号连续）。
- **参考文献条目空行**：文末「参考文献」每条之间必须空行分隔、各自成段——无空行的连续条目行在 Markdown 渲染器（知乎/Typora）中被合并成一段，整块黏连；check_gbt_refs 拦截条目间缺空行。
- **公式一律 LaTeX**：md 中所有数学内容（公式、变量、运算式）必须用行内 `$...$` 或块级 `$$...$$` LaTeX 书写（知乎渲染）；**禁止 Unicode 手写公式**（√∫∥∈π² 等字符写数学表达式）。docx 由 `report_to_docx.py` 把 `$...$` 转 OMML（Word 原生公式，默认模式）；md 保留 LaTeX 供知乎渲染。quality_check `check_math_formula` 硬性拦截正文中 `$...$` 之外的数学特征字符；`!` 在 `$...$` 内是阶乘/否定符号，不属感叹号（check_exclamation 已豁免）。
- 标注数据口径：如"展示产品口径""媒体估算""未见单一权威披露"。仍禁止"（一手/二手/推算）"等强度分级括注；如需说明来源性质，用"官方/媒体"等词直接写在叙述中。
- **独立组织**：正文不挂来源名之外，内容结构/小节组织/结论表述也不得照搬任何单一来源；来源只提供素材，组织框架与结论须综合多来源 + 公共知识独立完成。判断标准：来源文章的结构大纲与报告一一对应即抄袭；实践=换更通用的框架主线、补历史与算例、关键数字独立推导验证。
- **能用 1234 分点就用**：并列的多条同类信息（规格条目、能力清单、档位/等级、分项结果、要点列表等）一律用有序列表 `1. 2. 3.` 组织，禁止写成"第一……第二……"式长段落；**点数是内容决定的，禁止强行凑数/强行对称**（内容只有 2 条就写 2 点，有 5 条就写 5 点，单句信息并入叙述段不单独成点）。**能用表格就用表格**：多实体对照内容（如多模型基准对比表）用 Markdown 表格承载（纯文字多实体对比、清单、属性表），禁止写成"第一……第二……"式长段落；**涉及公式的内容不制作表格**——公式一律 LaTeX 写进正文叙述，表格单元格内禁止出现公式（quality_check 拦截）；**逐条内容用有序列表（1. 2. 3.）组织**，禁止无序 bullet 与长段落黏连。纯因果逻辑链叙述（推导过程、事件演化）才用文字。表格规则：先一句话交代表格意义，表后 1–2 句客观解读（不夹评价）。
- 涉及收益、风险等内容必须加风险提示，不构成投资/专业建议。

## 排版（Markdown，可直接粘贴知乎）

- 标题：`##` 起层级，不用 `#`。
- 分部分标题不带括号；如需说明来源性质，用"官方/媒体"等词直接写在正文叙述中，不放标题、不作括注。
- 强调：用 **加粗** 标注关键数据/名称——尤其结论句核心数字、算式结果、对比关键值（提升扫读性，知乎读者扫读路径靠加粗数字）；不用来强调观点。
- 列表：适度使用列表提升可扫读性，避免整篇堆砌。
- 引用来源用正文 [n] 引注，文末按 GB/T 7714-2015 著录参考文献；不使用脚注式来源链接。
- 不插入无意义分隔线和 emoji。

## 去 AI 味（重要）

目标是让读者觉得是「一个真实做过这行的人在陈述」，而非 AI 模板。写完后通读一遍，对照以下清单自查：

**表达层面**：

- 删掉框架词：先说结论、总结一下、总而言之、不难发现、值得注意的是、总的来说。
- 删掉"AI 腔"副词：其实、本质上、确实、显然、往往、某种程度上（保留一半即可）。
- 不用"其一其二""首先其次"；改用自然的段落过渡。
- 不用"据称/据说/传闻"式无出处引用；改"据 XX 数据/媒体报道"。
- 不用"不是……，是/而是……"转折句式（典型 AI 语言，如"不是定律，只是平均值"）；直接陈述事实（"1 万小时仅为最优秀组在单一时间点的平均值"）。
- 不用 AI 腔句式："之所以……是因为……""随着……的发展/到来""在……的背景下/在此背景下""在 XX 时代（如'在 AI 时代'）""可以看出/由此可见"——删掉背景铺垫与因果强调，直接给事实。
- 不用感叹号、反问句、煽动性表达。

**结构层面**：

- 小标题像事实目录，不像观点口号（如"产品结构""市场数据"而非"幻方不行"）。
- 段落间用事实衔接（"同期""此外""按该口径"），不用观点承接。

**数据层面**：

- 关键数字嵌进叙述，来源用"据 XX 数据"带过。
- 拆解/推算必须标注"推算"和口径假设。
- 来源链接放文末备查。

**自查办法**：通读全文，若出现任何价值判断词（应该/不该/说明/证明/可见）、情绪词、评价性形容词，删除或改为中性事实表述。

## 禁忌

- 不用「首先/其次/再次/最后」等套话开场。
- 不写「综上所述」「总而言之」式结尾。
- 不堆砌小标题凑字数；每节标题必须承诺内容。
- 不做断言式理财/医疗/法律建议。
- **不设结论、不表立场、不给建议、不替读者判断。**

## 配图禁忌

AI 概念图（封面/题图）必须为**纯抽象视觉**，严禁出现以下任何具象元素——

1. **任何语言文字**：汉字、英文、数字、字符、符号、logo、水印
2. **任何徽章与国徽**：国徽、国旗、警徽、军徽、校徽、企业徽、盾牌纹章、奖章、勋章、任何带图案的圆形或盾形徽标
3. **任何政府/司法/宗教建筑**：人民大会堂、政府大楼、法院、议会、教堂、寺庙、可识别的地标建筑
4. **任何货币与票据**：钞票、硬币、债券、纸币、票据、发票、彩票、价格标签、收据
5. **任何真实人脸与肖像**：清晰人脸、特定人物肖像、可识别名人
6. **任何特定国家/政治符号**：国旗、政党标志、政治标语

`tools/report_images.py` 的 `call_agnes` 末尾自动追加 `_AI_IMAGE_NEGATIVE_GUARD` 通用禁词句（no text / no emblem / no banknote 等全套英文 negative）确保所有 `--ai-prompts` 默认遵守；但**工具层面的 prompt 防御不替代人工复检**——生成后必须肉眼逐图扫一遍（重点扫门楣/中央/边缘的圆形徽标与飘字票据），发现违规立刻删图重生成，不要为了凑数保留违规图。

**封面图必须与问题主题相关**：封面/题图除合规外，**必须紧扣问题主题**——视觉应能映射问题的核心概念（如 LOF 退市→挤溢价泡沫+场内转场外；学术vs工业→书与机房的对话；半导体→晶圆/光刻意象）。**禁止使用与问题无关的纯装饰抽象图**（如"金色球体+棱柱"的通用科幻视觉，看似合规但读者看不出主题）。

写 prompt 流程：①提炼 2-3 个核心视觉符号（如 LOF 退市→"溢价泡沫=发光气泡群/退市闸口=几何门框/按净值赎回=规整立方体阵列"）；②围绕这些符号构造抽象叙事场景（左→中→右的视觉过渡即可直观映射问题逻辑）；③用 `--ai-prompts` 自定义 JSON 文件传入（默认 DEFAULT_AI_PROMPTS 旧模板"斩杀线/双档定价"等为历史 slug 遗留，对新主题往往无关，新研究一律覆盖）。自检：①不看标题，读者能否从图中识别本报告主题？答否则必须重做；②`process_notes.md` 同步记录"封面图主题相关性复检"与核心视觉符号的映射说明。

**封面图构图饱满**：封面/题图**禁止大面积空白/留白**——prompt 不得写"左下角留白适合叠加标题"等留白引导（标题由知乎发布时叠加，图内不留白）；画面构图必须饱满、平衡，视觉元素均匀铺满整个画布，边角不留白。`_AI_IMAGE_NEGATIVE_GUARD` 已含 "no large empty areas, no blank corners, no white space reserved for text overlay"；自定义 prompt 也不再写留白引导。复检时同步检查四角/边缘是否有大块均匀空白。
