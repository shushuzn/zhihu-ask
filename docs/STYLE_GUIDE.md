# 知乎文风与排版指南

回答正文的写作规范。核心原则：信息密度高、结构可扫读、数字可核查、语气像「懂行的真人」。

## 文风

- 口语化但有信息量，避免答辩腔；可偶尔用「说白了」「我的观察是」衔接。
- 直接给结论再给论证（知乎读者习惯先看观点）。
- 态度诚恳，承认不确定性；给「权衡」而非「唯一答案」。
- 全文至少一处具体数字或可验证事实作为记忆点。

## 结构

- 开头 1–2 句点明立场/答案，不铺垫。
- 用层级标题切分：大问题拆 3–5 个小节，每节聚焦一个问题。
- 每段不超过 4–5 行；一个段落只讲一个点。
- 结尾给出可操作清单或下一步建议，最好落回「你能做什么」。

## 数据呈现

- 数字、日期、百分比、金额必须带来源（括注或脚注链接）。
- 对比类内容优先用表格：先一句话交代表格意义，表后接 1–2 句解读。
- 涉及收益、风险等内容必须加风险提示，不构成投资/专业建议。

## 排版（Markdown，可直接粘贴知乎）

- 标题：`##` 起层级，不用 `#`。
- 强调：用 **加粗** 标注关键结论，一屏内不超过 2–3 处。
- 列表：适度使用有序/无序列表提升可扫读性，避免整篇堆砌。
- 引用来源用脚注式：`[来源：标题](链接)`。
- 不插入无意义分隔线和 emoji。

## 禁忌

- 不用「首先/其次/再次/最后」等套话开场。
- 不写「综上所述」「总而言之」式结尾。
- 不堆砌小标题凑字数；每节标题必须承诺内容。
- 不做断言式理财/医疗/法律建议。
