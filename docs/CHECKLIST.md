# 发布前质量检查清单

阶段 4 完成后、回答发布前，逐项核对。分「研究质量」与「回答质量」两组，任何一项不满足则返回修正。

## 研究质量

- [ ] 每个可量化数据（数字、百分比、金额、日期）都有来源链接。
- [ ] 每个关键数字标注数据级别（一手/二手/推断）。
- [ ] 媒体转述数字已尽量回溯一手来源；无法取得的一律标注「仅媒体口径」。
- [ ] 多源冲突的数据已标注并说明取舍依据。
- [ ] 无法核实的内容标注「未证实」，未被当作事实输出。
- [ ] 公众号引用保留「公众号名 + 文章标题 + 链接」。
- [ ] 关键结论至少被两个独立来源交叉印证（公众号/Web/插件任意组合）。
- [ ] 反方观点或风险提示已覆盖（针对有争议或涉及风险的议题）。
- [ ] 至少完成一项量化测算（市场规模/成本结构/情景推演），非形容词式判断。
- [ ] 利益相关方矩阵、对标比较、风险矩阵已覆盖（针对多维影响问题）。

## 回答质量

- [ ] 开头 1–2 句直接给出核心答案，无铺垫。
- [ ] 全文至少一处具体数字或可验证事实作为记忆点。
- [ ] 段落 ≤ 4–5 行，每段一个观点；层级标题承诺内容。
- [ ] 对比类内容使用表格，表前有说明、表后有解读。
- [ ] 至少 1 处量化/算账（成本/规模/比例），非形容词式判断。
- [ ] 至少 1 处对标比较（竞品/历史/国际）。
- [ ] 反方/争议观点已回应（认同/部分认同/不认同 + 理由）。
- [ ] 结尾给出可操作清单或「你能做什么」。
- [ ] 语气口语化但不轻浮，无套话（首先/其次/综上所述）。
- [ ] 涉及理财、投资、医疗、法律等给出风险提示与免责声明。
- [ ] 无 emoji、无多余分隔线；Markdown 可直接粘贴知乎。
- [ ] 去 AI 味（对照 STYLE_GUIDE）：无框架词（先说结论/总结一下）、无"其一其二"、立场明确不暧昧、数字嵌叙述、结尾不总结。
- [ ] 通读一遍，若金句过密/观点过于对称/段段像排比，继续往平实方向压。

数据可靠性（硬性，发布前必须全部通过）：
- [ ] 每个关键数字可溯源（正文或脚注给出来源），无一问三不知的数字。
- [ ] 推断/估算数字已明确标注"估算/推算"，未伪装成精确事实。
- [ ] 媒体转述的敏感数字标注了数据口径（如"展示产品口径"）。
- [ ] 全文无"据称/据说/传闻"式无出处引用。
- [ ] 无法核实的关键数据已明确说明或删去，而非含糊带过。
