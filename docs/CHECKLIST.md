# 发布前质量检查清单

> 阶段 4 完成后、报告交付前，逐项核对。分「研究质量」与「正文质量」两组，任何一项不满足则返回修正。

## 研究质量

- [ ] 每个可量化数据（数字、百分比、金额、日期）都有来源链接。
- [ ] 每个关键数字标注数据级别（一手/二手/推断）。
- [ ] 媒体转述数字已尽量回溯一手来源；无法取得的一律标注「仅媒体口径」。
- [ ] 多源冲突的数据已标注并说明取舍依据。
- [ ] 无法核实的内容标注「未证实」，未被当作事实输出。
- [ ] 公众号引用保留「公众号名 + 文章标题 + 链接」。
- [ ] 知乎引用保留「作者 + 标题 + 链接」（经 Web 检索/网页打开获取的知乎结果，含赞同数/权威等级时一并保留）。
- [ ] 关键结论至少被两个独立来源交叉印证（公众号/Web/插件任意组合）。
- [ ] 反方观点或风险提示已覆盖（针对有争议或涉及风险的议题）。
- [ ] 量化测算按需但必验：有计算价值的算式必须写（市场规模/成本结构/情景推演/对比拆解/证明机制），融入叙述；每条算式经 Python 验证、脚本留存（如 verify_calcs.py）；禁止凑数硬造也禁止该写不写。
- [ ] 测算逻辑链完整（若有测算）：每条含 假设前提/计算口径（含算式与数字）/量化结果（回引数字）/口径说明（含边界条件）——quality_check 逐条检测四要素+算式+量化结果。
- [ ] **论证完整（数学/证明/机制类内容）**：给完整论证链（定理-引理-证明或步骤归约），禁止只给方法名概述、禁止省略证明步骤；来源论文的论证结构以论文全文（arXiv HTML 版）为准，不凭摘要臆测。
- [ ] **非线性与多情景**：涉及未来预测/趋势判断时，必须给出至少 3 个情景（基准/加速/颠覆），写明触发条件与可观察信号；禁止只按当前趋势线性外推。
- [ ] **历史周期检验**：涉及“某行业/专业长期有前景”的判断，必须至少用 1 个历史反例（如房地产、教育扩招、互联网泡沫、土木工程由热转冷）检验当前热门是否会重演“人才过剩/行业衰退”，并说明目标对象与历史案例的异同。
- [ ] **可迁移与反脆弱**：结论必须包含“即使具体预测错误也能成立”的底层能力或策略，禁止只给具体专业/行业名单而无兜底逻辑。
- [ ] **不确定性标注**：预测类结论必须明确区分“方向性判断/概率性判断/事实”，并列出关键假设与失效条件；无法确定的部分写“待验证”或给区间。
- [ ] 小节数量由内容自然决定，不设上限；并列多条信息用有序列表 1. 2. 3.（quality_check 只检查小点是否未叙述化）。
- [ ] 利益相关方矩阵、对标比较、风险矩阵已覆盖（针对多维影响问题）。
- [ ] 迭代轮次达标（SOP A.8）：默认 1 轮（除非有内容无法一轮解决才追加）；可用 `python tools/check_progress.py --slug <slug> --require_round auto` 校验（auto 按项目统一最低轮次判定）。
- [ ] 研究启动时已查 flomo 已有笔记（SOP 阶段 1 步骤 0）：`memo_search` 搜问题主题词，relevance ≥0.9 复用/更新已有笔记、不重复新建；结果记录 plan.md。
- [ ] **已有笔记命中即复用（不重建目录）**：查重命中已有笔记但本地 `research/<slug>/` 目录缺失时，从 flomo 用 `memo_batch_get` 拉取命中笔记全文，在其基础上**只补新信息**，不重复研究、不重建目录。
- [ ] **旧笔记过时信息已更新**：新信息推翻旧笔记表述时（"尚无定论""待观察""未发布"等被证实/证伪），旧笔记中过时句子已原地更新（补结局或改写），未只新增笔记而留下自相矛盾的旧笔记；更新后的旧笔记与新增笔记一并质检上传。
- [ ] **flomo 笔记素材引用须有合规参考文献**：查重命中的 flomo 笔记可作参考素材，但须先跑 `python tools/check_flomo_note_refs.py --keywords "<主题词>"`——含**符合 GB/T 7714-2015** 的参考文献才可用；无参考文献联网找对应来源（找到相关候选须人工确认对应性）；联网找不到对应来源、或参考文献不合国标（缺类型标识/URL 缺日期/编号不连续）的笔记**不可用**，禁止引用。
- [ ] **适用通道全部执行完毕后才写报告**（SOP 阶段 1 流转条件）：F/E/A/B/C/P 六通道各有结果记录（素材落盘或"无有效素材/不适用/跳过"；P0 缺失须补足、P1 无命中记"无有效素材"、P2 记 skip），通道执行清单写入 plan.md；禁止只做部分通道即产出 report.md。
- [ ] **每通道硬数据须落到报告正文**：通道"执行过/落盘素材"≠交付完成——适用通道的硬数据（事实/数字/实体/结论）必须写入 report.md 正文相应小节（C 通道尤其易犯只记录不落正文）；`check_progress --require report_channels` 已接入 run_pipeline 收尾门禁，未通过阻断 docx/flomo 产出。
- [ ] **通道完成态已结构化登记**：`.progress.json` 的 `data.channels_done` 已登记六通道执行态（done/empty/skip + note，`mark_channel.py` 登记；A/B/P/F 落盘自动登记，E/C 未配置为环境级自动 skip）；`check_progress --require report_channels` 双向校验通过。
- [ ] **模块化笔记已上传 flomo**：`note_upload.py research/<slug>/notes/` 逐条质检后上传；索引笔记(00_index.md)与报告(report.md/report_draft.md)禁止上传（工具自动拦截；拦截/失败如实记录）；未配置则 process_notes 记录。误传的条目无法自删，如实告知用户手动清理。

## 正文质量（纯事实陈述）

- [ ] 开头直接进入事实（事件/数据/背景），无"结论先行"。
- [ ] 全文至少一处具体数字或可验证事实作为记忆点，且带来源与口径。
- [ ] 段落 ≤ 4–5 行，每段一个事实点；标题像事实目录。
- [ ] **可读性**：目标读者为对主题感兴趣的专业/准专业读者——术语首次出现给简洁准确的定义（不做生活化类比稀释），公式符号首次出现说明含义，逻辑链严密（先因后果）、数据与论证完整；机器无法可靠判定可读性，此项为人工复核。
- [ ] **概念主体**：正文叙述主体是概念/事件/对象本身，来源材料（链接/博客/论文）只用于提炼概念；正文无"以下解读 XX""XX 文章的价值在于""这篇论文讲了"等转述体句子（判断标准：删掉"这篇文章/博客/论文/解读"字样后正文依然成立）；句首禁止裸"这篇/该篇/本篇/此篇"指代（须接论文/文章/报告/研究/笔记等实体名词）；来源交代只放参考文献区。
- [ ] **独立组织**：内容结构/小节组织/结论表述不照搬任何单一来源（判断标准：来源文章的结构大纲与报告一一对应即抄袭）；来源只提供素材，组织框架与结论综合多来源 + 公共知识独立完成，关键数字独立推导验证。
- [ ] **公式一律 LaTeX**：数学内容（公式/变量/运算式）用 `$...$` LaTeX 书写，禁止 Unicode 手写公式（√∫∥∈π² 等字符写数学表达式）；quality_check `check_math_formula` 硬性拦截，交付前自查一遍。
- [ ] **能用 1234 分点就用**：并列的多条同类信息（规格条目、能力清单、档位/等级、分项结果、要点列表等）一律用有序列表 `1. 2. 3.` 组织，禁止写成"第一……第二……"式长段落；**点数是内容决定的，禁止强行凑数/强行对称**（内容只有 2 条就写 2 点、5 条写 5 点，单句信息并入叙述段不单独成点）。**能用表格就用表格**：多实体对照内容（纯文字多实体对比、清单、属性表）一律用表格承载，禁止"第一……第二……"式长段落；**涉及公式的内容不制作表格**——公式一律 LaTeX 写进正文叙述，表格单元格内禁止出现公式（quality_check 拦截表格行内 $ 或数学 Unicode 字符）；逐条内容（七类定理/多种约定等）用有序列表 1. 2. 3. 组织。纯因果逻辑链叙述才用文字。表前一句话交代表格意义、表后 1–2 句客观解读。
- [ ] 至少 1 处结构性拆解（归因/构成/成本拆分），推算已标注"推算"与口径假设。
- [ ] 至少 1 处对照数据（历史/行业/国际）。
- [ ] 涉及理财、投资、医疗、法律等给出风险提示与免责声明。
- [ ] 无 emoji、无多余分隔线；Markdown 可直接粘贴知乎。
- [ ] 去 AI 味（对照 STYLE_GUIDE）：无框架词（先说结论/总结一下）、无"其一其二"、无感叹号/反问句、数字嵌叙述。

**立场中立（硬性，发布前必须全部通过）**：

- [ ] 无"我认为/我的判断/结论很硬/显然/可见/证明"等立场词。
- [ ] 无评价性形容词（太猛/很差/厉害/离谱）与贴标签。
- [ ] 无"应该/不该/建议/最好"式价值建议。
- [ ] 无"总之/所以结论是"式总结判断。
- [ ] 判断权完全留给读者。
- [ ] 已运行 `python tools/quality_check.py --file <报告>`，检出项已人工确认（未误杀合法用法）。
- [ ] 参考文献按 GB/T 7714-2015 编号著录（条目含类型标识/出版信息/URL 与引用日期），无"一手/二手/推断"等分级标注。

**数据可靠性（硬性，发布前必须全部通过）**：

- [ ] 每个关键数字可溯源（正文 [n] 引注或文末参考文献），无一问三不知的数字。
- [ ] 推断/估算数字已明确标注"估算/推算"，未伪装成精确事实。
- [ ] 媒体转述的敏感数字标注了数据口径（如"展示产品口径"）。
- [ ] 全文无"据称/据说/传闻"式无出处引用。
