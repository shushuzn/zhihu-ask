## 二、使用规则

1. **领域选库**：研究问题确定领域后，从本表取对应分组的库（金融类默认金融组+行业研究组；涉企主体加公告/行业组；法律类取法律组；AI 类取 AI 组；农业类取农业组；通用问题先 `search_knowledge_base "主概念"` 定位，不限定本表）。
2. **检索**：对每个候选库执行 `search_knowledge (knowledge_base_id, query)`，query 用 plan.md 关键词组（同通道 A 的词，可简化）。
3. **落盘**：命中条目写入 `research/<slug>/gathered_ima.md`（格式见 `docs/TOOLS.md` ima 章节），含 库名/标题/类型/摘要/命中片段/时间/media_id。
4. **正文**：阶段 3 交叉验证需要原文时，`fetch_media_content(media_id)` 读取。
5. **维护**：ima 端订阅变化后回填本表；新增库按领域归类，失效库（`search_knowledge` 报错/空结果）标记并移除。2026-08-09 快照基于接口枚举，未列入的低价值库可用 `search_knowledge_base` 按名检索发现。
