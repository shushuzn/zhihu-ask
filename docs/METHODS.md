# 可复用分析方法

经实证沉淀的分析框架。用于阶段 3 综合与阶段 4 生成，避免每题从零构思。

## 一、数字漏斗拆解法（适用于"XX 利好 N 万家/亿企业"类问题）

媒体常把一个广义数字与特定事件挂钩制造传播效果。拆解公式：

1. **拆口径**：N 万家的统计口径是什么？（如"XX 相关企业"广义标签 vs 与事件真正相关的企业）
2. **逐层收窄**：广义标签数 → 直接相关企业数 → 与本次事件直接相关数（通常≈0）。
3. **引用可查证据**：找到每一层的可核实数字（如天眼查/企查查/产业报告），标注来源与年份。
4. **结论模板**：科学上真突破 / 产业上远未到来；对 N 万家中 99% 无即时影响。

实证案例（脱敏示例）：某材料技术事件——N 万家企业（广义行业标签）→ 约 X 万家（业务涉及该材料）→ 与事件中具体前沿结构直接相关≈0。

## 二、四层影响分层法（适用于"技术突破对产业有何影响"）

不笼统说"利好/利空"，把影响拆成四层：

| 层级 | 内容 | 判断要点 |
|---|---|---|
| 直接技术受益 | 与突破直接相关的下游赛道 | 该赛道当前市场规模多大？处科研/样机/量产哪阶段？ |
| 生态与人才受益 | 科研生态、高端装备、上游材料 | 长期效应，跟踪即可 |
| 情绪与资本市场 | 概念股、新闻叙事 | 查同类概念炒作史，警惕脱节 |
| 绝大多数企业 | 无影响 | 客户与工艺不因论文改变 |

## 三、科研新闻 vs 产业新闻 判别法

- 问三个问题：发在什么期刊（顶刊/普通刊/未发表）？样品尺寸到应用级别差几个数量级？从实验室到规模化参考同类技术用了多久（同类前沿材料 CVD 法从实验室到初步规模化约十几年）？
- 若三问答案都不乐观，则定性为"科研新闻"，产业影响以长期生态为主。
- 时间尺度提示：科研→样机→小批量→规模化，通常以十年计。

## 四、市场规模口径警示

同一名词不同机构数字可差十倍（某新兴材料市场各机构预测从百亿元到千亿元量级不等）。规则：
- 一律标注来源与口径（粉体/薄膜/应用/全行业）。
- 采用与主流公开报道一致的中位区间，极端乐观预测标注"该机构口径"。
- 报告与回答中给区间而非单一数字。

## 五、反方视角补位法

任何涉及"突破/机遇/利好"的回答，至少补一条反方：
- 搜「主题 + 质疑/泡沫/失败/反面案例/风险」。
- 标注反方观点的证据强度（论文/数据支撑 / 行业观点 / 猜测）。
- 回应策略：反方点成立则吸收进结论；夸大的则说明理由。
