# 可复用分析方法

经实证沉淀的分析框架。用于阶段 3 综合与阶段 4 生成，避免每题从零构思。

## 一、数字漏斗拆解法（适用于"XX 利好 N 万家/亿企业"类问题）

媒体常把一个广义数字与特定事件挂钩制造传播效果。拆解公式：

1. **拆口径**：N 万家的统计口径是什么？（如"XX 相关企业"广义标签 vs 与事件真正相关的企业）
2. **逐层收窄**：广义标签数 → 直接相关企业数 → 与本次事件直接相关数（通常≈0）。
3. **引用可查证据**：找到每一层的可核实数字（如天眼查/企查查/产业报告），标注来源与年份。
4. **结论模板**：科学上真突破 / 产业上远未到来；对 N 万家中 99% 无即时影响。

实证案例（脱敏示例）：某材料技术事件——N 万家企业（广义行业标签）→ 约 X 万家（业务涉及该材料）→ 与事件中具体前沿结构直接相关≈0。

## 二、四层影响分层法（适用于"技术突破对产业有何影响"）

不笼统说"利好/利空"，把影响拆成四层：

| 层级 | 内容 | 判断要点 |
|---|---|---|
| 直接技术受益 | 与突破直接相关的下游赛道 | 该赛道当前市场规模多大？处科研/样机/量产哪阶段？ |
| 生态与人才受益 | 科研生态、高端装备、上游材料 | 长期效应，跟踪即可 |
| 情绪与资本市场 | 概念股、新闻叙事 | 查同类概念炒作史，警惕脱节 |
| 绝大多数企业 | 无影响 | 客户与工艺不因论文改变 |

## 三、科研新闻 vs 产业新闻 判别法

- 问三个问题：发在什么期刊（顶刊/普通刊/未发表）？样品尺寸到应用级别差几个数量级？从实验室到规模化参考同类技术用了多久（同类前沿材料 CVD 法从实验室到初步规模化约十几年）？
- 若三问答案都不乐观，则定性为"科研新闻"，产业影响以长期生态为主。
- 时间尺度提示：科研→样机→小批量→规模化，通常以十年计。

## 四、市场规模口径警示

同一名词不同机构数字可差十倍（某新兴材料市场各机构预测从百亿元到千亿元量级不等）。规则：
- 一律标注来源与口径（粉体/薄膜/应用/全行业）。
- 采用与主流公开报道一致的中位区间，极端乐观预测标注"该机构口径"。
- 报告与回答中给区间而非单一数字。

## 五、反方视角补位法

任何涉及"突破/机遇/利好"的回答，至少补一条反方：
- 搜「主题 + 质疑/泡沫/失败/反面案例/风险」。
- 标注反方观点的证据强度（论文/数据支撑 / 行业观点 / 猜测）。
- 回应策略：反方点成立则吸收进结论；夸大的则说明理由。

## 六、数据来源分级法（智库报告基线）

智库报告与媒体综述的根本差异在证据层级。所有关键数据必须分级标注：

| 级别 | 定义 | 示例 |
|---|---|---|
| 一手 | 原始发布者：官方文件、论文、财报、交易所公告、监管数据 | 统计局、招股书、Nature 论文、央行公告 |
| 二手 | 可靠转述：权威媒体引用一手来源、行业协会报告 | 官方通讯社、券商研报引用原始数据 |
| 推断 | 基于已有数据的测算/外推，须说明假设 | 市场规模测算、增长预测、情景推演 |

规则：
- 一手数据直接引用；二手数据注明"据 XX 引用"；推断数据必须给假设与区间。
- 每个关键数字旁标注级别（一手/二手/推断）。
- 若同一数据多源冲突，列出冲突各方的口径与级别，再给判断。

## 七、量化测算法

智库报告必有至少一项"算账"环节，把模糊判断变成可检验的数字：
- 常见测算：市场规模（口径+增速+区间）、成本结构拆解（各环节占比）、单价/毛利变化、情景推演（保守/中性/乐观三档）。
- 格式：给假设前提 → 给计算口径 → 给结果区间 → 给敏感性（哪个变量最影响结果）。
- 若因数据不足无法量化，明确说明，并给出替代的可观察指标（如"用招聘数/专利数/装机量作为先行指标"）。
- 反例：只有"影响很大""显著利好"这类形容词而没有数字，视为不合格。

## 八、利益相关方分析矩阵

对涉及多方影响的问题，用矩阵代替笼统判断：

| 利益相关方 | 影响方向（利好/利空/中性） | 影响程度（大/中/小） | 时间尺度（短/中/长期） | 判断依据 |
|---|---|---|---|---|
| 直接下游 | | | | |
| 供应商/上游 | | | | |
| 竞争者 | | | | |
| 消费者/用户 | | | | |
| 监管/政策 | | | | |
| 资本市场 | | | | |

## 九、对标比较法

智库结论必须有参照系，否则"重要/昂贵/罕见"无从谈起：
- 时间对标：与同类历史事件/周期比（如与历次调价、历史上同类技术产业化周期比）。
- 空间对标：与国际/行业/竞争对手比（如"该价格相对海外竞品贵/便宜多少倍"）。
- 规模对标：与相邻市场/公司/指标比（如"该细分市场占整个行业比例"）。
- 输出形式：一两个对标表或对标句子，让结论有锚点。

## 十、风险矩阵法

把"可能有风险"升级为结构化风险清单：

| 风险 | 概率（高/中/低） | 影响（大/中/小） | 证据强度 | 应对/观察指标 |
|---|---|---|---|---|
| | | | | |

规则：每个风险必须给证据强度（数据支撑/行业观点/猜测）；结论中显著依赖的风险要单独说明，避免读者误以为报告是确定性预测。
